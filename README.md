## 协作规则

1. **设定以 [世界观.md](世界观.md) 为准。** 写作时若与设定冲突，改自己的章节；确实需要改设定，先提 PR 改 [世界观.md](世界观.md)，再改章节。
2. **只改自己那一章。** 别人的章节有问题，开 issue 或在 PR 里说，不要直接改。
3. **一章一个分支一个 PR**，分支名建议 `chapter-2-雾林` 这样。
4. **排版统一**：全角标点，引号用中文弯引号（“…”），破折号用 `——`。正文以 `# 第X章：标题` 开头。

## 章节衔接（动笔前必读）

- **第二章（雾林）**：第一章结尾已经把马来和栖送进了梦境的入口——雾中传来酷似母亲的呼唤“马来……”，马来抬蹄要走，栖展开受伤的翅膀挡住了那片浓雾。请从这个瞬间接着写，不要重述入梦过程。另外第三章开篇设定“雾在身后合拢、来路消失”，所以本章的收尾请落在**走出雾林、回不了头**上。
- **第四章（狼影之地）**：第三章结尾已经递了钩子——“前方，暮色之中，天边隐约浮动着几道灰影，像狼的轮廓”。请从这里接。
- **共用母题**（前两章已经立住，后续可复用）：栖那声微弱的“啾”、“再走一步”、干草堆的暖色、“候鸟迁徙从不回头”。
